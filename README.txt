HOW TO USE IN MICROSOFT EXPRESSION WEB
1. Extract this folder.
2. Open the folder as your website/project in Expression Web.
3. Keep all six HTML files and style.css together in the same main folder.
4. Put your photos inside the images folder and use the exact filenames shown in the HTML:
   home.jpg, about.jpg, bedroom.jpg, coworking.jpg, kitchen.jpg,
   laundry.jpg, lounge.jpg, security.jpg
5. Open index.html to preview the website.

IMPORTANT
- Replace the sample email, phone number and address on contact.html.
- The contact form is only a visual/front-end form until connected to a form service or server.
- Review facilities, package descriptions and FAQ answers. Keep only features and policies that are actually true for SkyNet.
- Google Fonts are loaded online; Georgia is used as the normal text font.
